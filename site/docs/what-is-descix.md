# What is DeSciX?

DeSciX is a **DEX + App Store for chain-tracked IP rights**. Build intellectual property—whatever you can imagine and build—with DeSciX SDKs; operate, deliver, and monetize it on DeSciX's scalable platform; and capture value via **IP-IPOs**.

## Build

Create IP using DeSciX SDKs and tools:

- AI-enabled DApps
- Super-computer cores
- Interactive books
- Games
- Knowledge bases and CodeSites

All of these embody community-owned intellectual property and are deployed through the DeSciX App Store.

## Operate & Deliver

The DeSciX platform provides scalable infrastructure for:

- Hosting and delivery via an infinitely scalable AI microservice mesh
- Edge-cached PWA for fast, global access
- Custom domain support for branded deployments

## Monetize

Value flows through **IP-IPOs**—the community-controlled pathway from private R&D to public market liquidity:

- Community tokens (DAITA_V2) with controlled auctions and earn/burn tokenomics
- Pre-IP-IPO: non-transferable tokens, price discovery via on-chain auctions
- Post-IP-IPO: unrestricted public DEX trading

## Identity & Payments

**[Powch](architecture/powch-defi-sso.md)** is the DeFi Banking + SSO layer across the DeSciX DAO/DEX ecosystem. One passkey-based identity, zero-knowledge shared userbase, passwordless one-touch login, and crypto with credit-card convenience—backed by hardware-wallet-grade security and anonymity.
